### Title of Dataset
PacBio HiFi (Revio) sequencing of the GIAB Ashekenazi Jewish Son (HG002) NIST Reference Material

### Background
HiFi whole genome sequencing of the GIAB Ashekenazi Jewish Family Trio NIST Reference Materials was performed by PacBio. HiFi reads were generated using the Revio system and aligned to three reference genomes; GRCh38-GIABv3, GRCh37 and CHM13.

### SEQUENCING METHODS

**Library Preparation**     
6 ug of DNA for each sample was sheared with Megarupter 3 (Diagenode, B06010003). PacBio libraries were prepared following "Preparing whole genome and metagenome libraries using SMRTbell® prep kit 3.0" (PN 102-166-600 REV02 MAR2023). The quantity of sheared DNA going into SPK3 library prep was 4.2, 4.38 and 4.5 ug for HG004, HG003, and HG002, respectively. SMRTbell libraries were size selected with PippinHT (Sage Science) and 10kb cut.

**Sequencing Platform**  
PacBio Revio System  
Instrument Control Software Version: 12.0.4.197734, Primary SW Version: 12.0.4.197734  

**Sequencing Method/Chemistry**  
Samples were prepared for sequencing using Revio polymerase kit (PN 102-817-600) and sequenced using Revio sequencing kit (PN 102-587-400) and Revio SMRT Cells (PN 102-202-200). 24 hour movies were run. Two SMRT Cells were run for each sample.  

### MAPPING METHODS PERFORMED BY NIST

Mapping was performed using [pbmm2 v1.10.0](https://github.com/PacificBiosciences/pbmm2/releases/tag/v1.10.0) and was run as part of the [PacBio HiFi-human-WGS_WDL (germline) pipeline v1.1.0](https://github.com/PacificBiosciences/HiFi-human-WGS-WDL). HiFi reads were generated with methylation calls, however methylation has not been assessed. Alignments were generated to three reference genomes:

| Reference     | Link to reference file used by GIAB                                                                                                                                              |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GRCh37        | [GRCh37](https://ftp-trace.ncbi.nlm.nih.gov/ReferenceSamples/giab/release/references/GRCh37/hs37d5.fa.gz)                                                                           |

### QUALITY ASSURANCE PRACTICES

[Cramino v0.14.5](https://github.com/wdecoster/cramino) was installed using Conda, and used for quality assessment of the resulting pbmm2 bam file.

Example QC command:

```
cramino -t 22 --reference ${ref} --hist --checksum --arrow HG002_GRCh38_GIABv3_PB-HiFi-Revio_20231031_cramino.arrow --karyotype --phased ${mapped_bam} > ${cramino_out}
```
